# A 题 · 深层非常规油藏多流体注入开发的多场建模与参数优化

英文题名为 *Multi-Field Modeling and Parameter Optimization for Multi-Fluid Injection Development in Deep Unconventional Reservoirs*。

题包的 A 题目录含附件 `Synthetic_Production_Data（英文版）.xlsx`。首张工作表有 38,880 条数据记录和 7 列，`Case_ID` 有 3 个不同取值。

| 字段 | 含义 |
| --- | --- |
| `Case_ID` | 工况标识 |
| `Nano_Concentration_wt%` | 纳米材料质量百分浓度 |
| `Soak_Time_Days` | 浸泡时间（天） |
| `Production_Day` | 生产日 |
| `BHP_MPa` | 井底压力（MPa） |
| `Oil_Rate_m3_d` | 日产油量（m³/天） |
| `Cum_Oil_m3` | 累计产油量（m³） |

当前已核对附件结构。[组委会题面与赛题包](https://www.nmmcm.org.cn/Awards/228.html)

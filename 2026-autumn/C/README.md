# C 题 · 无人超市补货作业的状态估计与决策优化

英文题名为 *State Estimation and Decision Optimization for Restocking Operations in Unmanned Supermarkets*。

题面使用 EgoDemo、EgoPro 和 EgoStandard 三组采集数据，共 69 条序列、66,070 个时间戳。作业视频与手部轨迹等数据由组委会单独分发。当前整理了数据入口，尚无训练结果。

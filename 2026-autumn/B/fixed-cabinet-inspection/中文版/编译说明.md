# 固定机柜巡检论文中文版

《固定设施巡检_修订版_中文.pdf》是完整中文论文。英文修订稿、算例输入、六个求解脚本和数值结果在上一级“固定设施巡检”目录。中文稿沿用同一组计算结果。

## 编译中文论文

在本目录运行下列命令。输出为 `paper_zh.pdf`。请使用带 xeCJK、Fandol 字体和模板所需宏包的 XeLaTeX 环境。若本工作区使用配套的 TinyTeX 补充目录，可先运行 `export TEXMFHOME="$PWD/../../.mathmodel/texmf"`。

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error paper_zh.tex
```

摘要、引言、结论与文献在 `paper_zh.tex`，第一、二问在 `measurement.tex`，第三、四问在 `calibration_schedule.tex`。基础表格和附录时间线在 `tables_zh.tex`。第四问的三行队列表由数值结果自动生成，中英文共用上一级目录的 `tradeoff_rows.tex`。编译时保留这两个目录的层级。

## 重绘图表与核验数据

五幅中文矢量图已随稿提供，可直接用于排版。在本目录运行 `python render_figures_zh.py` 可根据上一级目录的 JSON 结果重绘。重绘环境需安装上一级目录 `requirements.txt` 中的包，以及脚本支持的中文字体（例如思源黑体）。

在上一级目录运行 `python reproduce.py --verify` 可核验原始算例及英文修订稿的文件哈希。计算与复现步骤详见上一级目录的《中文解读.md》。
